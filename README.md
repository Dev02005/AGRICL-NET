# AgriCL-Net

Plant disease diagnosis from a leaf photo: disease name, lesion mask, severity
(Mild / Moderate / Severe) and advice, with a classifier that learns new
diseases without forgetting old ones. Design: `files/new files/`.

## Layout

| Path | Contents |
| --- | --- |
| `agricl/` | Python package (severity, data loading, models, inference) |
| `scripts/` | Dataset download and inspection scripts |
| `tests/` | Unit tests (`pytest`) |
| `notebooks/` | Colab/Kaggle training notebooks (GPU) |
| `data/` | Datasets, not committed |
| `files/old files/` | Base papers, paper notes, original documentation and slides |
| `files/new files/` | Revised documentation (`New Document.docx`) and the list of changes (`Changes.docx`) |

## Local setup (CPU)

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest -q tests
```

Training runs on Colab or Kaggle GPUs; this laptop has no NVIDIA GPU.
PyTorch is installed in `.venv` but will not load on this PC until the
Microsoft Visual C++ Redistributable (x64) is installed.

## Colab notebooks

The notebooks clone this repository from GitHub, so push changes before
running them. Dataset, SAM2 checkpoint and results are kept on Google Drive
under `MyDrive/AGRI-NET/`.

1. `notebooks/01_lesion_segmentation.ipynb`: trains the SAM2-UNet lesion
   model. Run once with `SMOKE_TEST = True`, then with `False`.
2. `notebooks/02_leaf_and_severity.ipynb`: SAM2 leaf masks and severity,
   compared on seen vs. unseen diseases. Needs a finished run of notebook 01.
3. `notebooks/03_disease_classifier.ipynb`: Swin-T classifier on lesion
   crops of the 112 seen diseases, with calibration and unknown-disease
   detection. Independent of notebooks 01 and 02.
4. `notebooks/04_continual_learning.ipynb`: learns the diseases in 5 rounds
   (grouped by crop) and compares fine-tuning, replay, and replay with
   knowledge distillation and weight aligning (AgriCL-Net). Uses notebook
   03's result as the joint-training upper bound if it exists.

5. `notebooks/05_app_bundle.ipynb`: packs the trained models into
   `MyDrive/AGRI-NET/agricl_app_bundle.zip` for the app and tests it.
6. `notebooks/06_edge_models.ipynb`: distils LinkNet-ResNet18 (lesions) and
   MobileNetV3 (classifier) students, exports them to ONNX, quantizes to INT8
   and reports size, speed and accuracy. Output:
   `MyDrive/AGRI-NET/agricl_edge_bundle.zip` (runs without PyTorch).
7. `notebooks/07_results_report.ipynb`: gathers all finished runs into
   `MyDrive/AGRI-NET/report/` (`report.md` tables plus charts for the
   documentation). CPU runtime is enough.

All notebooks are generated by `scripts/make_notebooks.py`; edit that script,
not the .ipynb files.

## Run the app

The app works from phone width up (columns stack below 640 px; the camera
option opens the phone camera) and uses Material icons only, no emojis.
Settings live in `.streamlit/config.toml`; run it from the project folder.

Demo mode (no models; previews the interface, not a real diagnosis):

```bash
.venv/Scripts/streamlit run app/streamlit_app.py
```

With the trained models:

1. Install Python 3.12 and the Microsoft Visual C++ Redistributable (x64).
2. `py -3.12 -m venv .venv-app` then
   `.venv-app/Scripts/python -m pip install -r requirements-app.txt`
3. Unzip the bundle from notebook 05 into `models/bundle/`.
4. `.venv-app/Scripts/streamlit run app/streamlit_app.py`

With the edge models (no PyTorch; Python 3.11 to 3.14, also on a Raspberry Pi
with 64-bit Raspberry Pi OS Bookworm):

1. `python -m pip install -r requirements-edge.txt`
2. Unzip the bundle from notebook 06 into `models/edge_bundle/` and set that
   folder in the app's sidebar, or benchmark it from the command line:
   `python scripts/edge_benchmark.py --bundle models/edge_bundle --images <photos>`

Photos the app cannot identify are saved to `unknown_images/` for the next
continual-learning round.

## Datasets

- PlantSeg v7: https://zenodo.org/records/17719108 (CC BY-NC 4.0), saved to `data/raw/plantseg.zip`
- PDSNets dataset: https://doi.org/10.34740/kaggle/ds/6620728 (Kaggle)
- PlantVillage: classification only
