# AgriCL-Net

Plant disease diagnosis from a leaf photo: disease name, lesion mask, severity
(Mild / Moderate / Severe) and advice, with a classifier that learns new
diseases without forgetting old ones. Design: `files/new files/`.

## Layout

| Path | Contents |
| --- | --- |
| `agricl/` | Python package (severity, data loading, models, inference) |
| `scripts/` | Dataset download and inspection scripts |
| `tests/` | Unit tests (`pytest`) |
| `notebooks/` | Colab/Kaggle training notebooks (GPU) |
| `data/` | Datasets, not committed |
| `files/old files/` | Base papers, paper notes, original documentation and slides |
| `files/new files/` | Revised documentation (`New Document.docx`) and the list of changes (`Changes.docx`) |

## Local setup (CPU)

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest -q tests
```

Training runs on Colab or Kaggle GPUs; this laptop has no NVIDIA GPU.
PyTorch is installed in `.venv` but will not load on this PC until the
Microsoft Visual C++ Redistributable (x64) is installed.

## Step 1: lesion segmentation (Colab)

1. Upload the `agricl/` folder to Google Drive at `MyDrive/AGRI-NET/agricl`.
2. Open `notebooks/01_lesion_segmentation.ipynb` in Colab with a T4 GPU.
3. Run it once with `SMOKE_TEST = True`, then set it to `False` and run all.

The notebook is generated by `scripts/make_lesion_notebook.py`; edit that
script, not the .ipynb. Results go to `MyDrive/AGRI-NET/runs/<run>/`.

## Datasets

- PlantSeg v7: https://zenodo.org/records/17719108 (CC BY-NC 4.0), saved to `data/raw/plantseg.zip`
- PDSNets dataset: https://doi.org/10.34740/kaggle/ds/6620728 (Kaggle)
- PlantVillage: classification only
